# Parked

Ideas for campaigns that have not been started. A folder here is **not** a campaign: the
leading `_` on this directory keeps it out of `list_campaigns()`, so `validate.py --all`,
`state.py` and the dashboard never treat it as one.

Nothing in here is live state. Nothing in here is canon. When one of these becomes a real
campaign, run `python3 tools/new_campaign.py "<name>"` and carry the pitch across by hand.
