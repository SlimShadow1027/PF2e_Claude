# GM-private — {{CAMPAIGN_TITLE}}

> **The convention:** the player has agreed not to read this folder. That agreement is the
> only thing protecting it, and it is enough.

Nothing in here is printed into chat unless the player explicitly asks for a spoiler.

| File | What it holds |
|---|---|
| `secrets.md` | twists, hidden NPC agendas, planned reveals |
| `seeds.md` | planted foreshadowing and where it is meant to pay off |
| `relationships.md` | the full NPC graph, including hidden allegiances (`tools/graph.py`) |
| `prep/NNN-YYYY-MM-DD.md` | between-session world prep reports |

GM-only material can also live inside a shared file, inside a fenced block:

```
> **GM-ONLY**
>
> what the player should not know
```

An off-screen turn writes here and nowhere the player reads, except for the spoiler-free
world pulse it hands to the next session's recap.
